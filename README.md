# She Builds WWW

Portfolio website for She Builds WWW. Plain HTML, CSS and JavaScript, hosted on Netlify from GitHub.

## Files

index.html is the homepage, styles.css holds the design, script.js runs the mobile menu, and thank-you.html is where the contact form lands after an enquiry is sent.

## Images

images/work holds the portfolio screenshots, each saved in three versions so phones download a smaller file:
1. stacy-johnstone-hair (hero and Selected Work)
2. dubai-off-plan-homes (Selected Work)
3. rumour-hair-extensions (Selected Work)

images/founder holds the founder photograph used in the About section.

To swap a screenshot later, replace all three versions of it (the 900 and 1800 .webp files and the .jpg) using the same filenames.

## Contact form

The form uses Netlify Forms. Enquiries appear under Forms in the Netlify dashboard, where email notifications can be switched on.
