# She Builds WWW

Portfolio website for She Builds WWW. Plain HTML, CSS and JavaScript, ready for GitHub and Netlify.

## Files

index.html is the homepage, styles.css holds all the design, script.js handles the menu and scroll effects, thank-you.html is where the contact form lands after someone sends an enquiry, and the images folder holds your screenshots.

## Deploying

1. Upload everything in this folder to a new GitHub repository.
2. In Netlify, choose Add new site, then Import from GitHub, and pick the repository. No build command is needed and the publish directory is the root.
3. Add shebuildswww.com under Domain management.
4. The contact form works automatically through Netlify Forms. Enquiries appear under Forms in your Netlify dashboard, and you can switch on email notifications there.

Update the email address in index.html if you use something other than hello@shebuildswww.com.
